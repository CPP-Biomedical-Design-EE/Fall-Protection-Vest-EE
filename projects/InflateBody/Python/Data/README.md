# Shared sample data

This folder contains a small labeled sample set for team testing:

- `adl_T01_standing`
- `adl_T04_jump`
- `adl_T07_walk_fast`
- `fall_T34_walking_slip_backward`

The complete P01 recordings and calibration files remain local to the data
collector. These samples are for replay and software testing only. They do not
prove fall-detection accuracy or safety performance.
